# Original expedition

The earlier 24-mission Hike Trail remains playable at [`/classic.html`](https://kaydanv.github.io/Trail-trials/classic.html). Version 5 is the 104-encounter Living Valley adventure.

Moving the original entry page did not change its origin or browser storage keys. Existing journeys and JSON backups remain supported. Source modules, styling, assets and test coverage remain in the repository to preserve the game.

Legacy browser checks automatically visit `classic.html`. `TRAILS_URL` selects the server origin; `LEGACY_URL` can override the exact legacy entry URL.

Historical original-game design and validation are recorded in [FOUNDATION.md](FOUNDATION.md), [VALIDATION.md](VALIDATION.md), and [PLAYTEST.md](PLAYTEST.md). Those records describe their named builds, not the current release results. See [V5_RELEASE.md](V5_RELEASE.md) for the current release.
